# Exemples de courriers anonymisés

Deux archives de courriers Word anonymisés (initiales à la place des noms de
patients), fournies par le médecin pour adapter le logiciel : déclencheurs de
demandes, canevas des lettres dérivées, style des courriers aux généralistes.

Les fichiers suivants ont été retirés des archives d'origine parce que le nom
complet ou la date de naissance du patient y figurait encore : PATIENT_000186,
000727, 001071, 001790, 001815 à 001831, 001967. Ils ne doivent pas être remis
dans le dépôt sans anonymisation.
